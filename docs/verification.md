# 验证说明

## 自动测试范围

| 验证 | 覆盖内容 | 外部依赖 |
| --- | --- | --- |
| Agent 后端测试 | 会话上下文、任务幂等、事件、文件、权限边界、演示规划和局部修订 | 模拟模型和 RAG，不调用真实 API |
| RAG 测试 | 解析、切分、索引、检索、入库回滚、原文访问 | 测试替身与临时目录；需安装 RAG 测试依赖 |
| 工作台浏览器测试 | 会话、引用、执行事件、文件下载、重试和移动端 | 本地模拟服务及浏览器 |
| HTML 浏览器测试 | 隔离预览、证据展开、图解、离线打开和版本恢复 | 本地模拟服务及浏览器 |
| 离线示例检查 | 逐页布局溢出、图片、导航和交互 | Edge 或 Playwright Chromium |

具体命令见 [测试手册](html-testing-guide.md)。测试输出写入本地 `data/`，不随源码分发。

## 已有开发验证

开发版本已通过 41 项 Agent 后端测试、53 项 RAG 测试和 17 组浏览器检查。真实外部链路也验证过论文入库、演示生成和后续仅修改指定页面标题；逐字段检查确认其他页面及演示设置得到保留。

以上为开发阶段的验证记录摘要，不代表在所有机器、模型或依赖版本下都会得到相同结果。公开副本不包含私人运行日志、论文、历史会话或生成文件，读者可根据测试手册重新验证。

## 发布副本整理后的检查

本次在源码副本的隔离测试目录中重新执行：41 项 Agent 后端测试通过，53 项 RAG 测试通过，7 页离线示例浏览器规则检查通过。RAG 测试有 3 条依赖弃用提示，没有测试失败。

检查复用了已有的 Windows / WSL Python 依赖和本机浏览器，未调用真实模型服务，也未验证全新机器安装。测试产生的数据和日志保存在副本之外；分发目录保持只有源码、模板、示例和文档。

## 跨机器配置适配后的复现

后续已完成两个全新 CPU API 虚拟环境的安装与启动，新增环境配置回归后，Agent 测试为 47 项、RAG 测试为 57 项，另有 7 组 HTML 工作台浏览器检查通过。独立 Compose、实际模型服务、PDF 入库、HTML 生成及连续局部修改也已验证。GPU 环境和权重仍为显式复用，详情及验证边界见 [干净目录复现记录](reproducibility.md)。

## 验证边界

自动规则检查覆盖结构、运行、布局溢出和交互，不证明所有学术论断准确，也不代替视觉审美或人工研读。模型与 RAG 的真实验证需要自行配置服务，并会产生模型调用和本地数据写入。
