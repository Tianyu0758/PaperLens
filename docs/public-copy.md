# 发布副本整理说明

此目录是 PaperLens 的独立发布副本，包含运行所需的源码、测试、示例及文档；原开发项目与其本地运行数据保持独立。

## 保留内容

- Agent 和 RAG 服务源码、前端静态资源。
- 后端与浏览器测试、测试依赖声明。
- 离线模拟演示、演示结构化稿和生成示例。
- 启动脚本、配置模板、依赖清单。
- 设计、接口、操作和验证说明。
- 经审查的工作台截图、架构图及 1 分 41 秒流程演示视频。
- MIT 许可和第三方组件、模型与论文素材的来源说明。

## 排除内容

- 实际 `.env`、访问凭据、虚拟环境和 Node 依赖目录。
- 数据库、论文 PDF、BM25 索引、上传文件、会话及生成产物。
- 运行日志、原始录制文件、临时截图、测试下载文件和缓存。
- 依赖相邻旧项目的文件哈希清单及检查脚本。
- 读取固定历史会话的截图脚本、私人联调标识和重复项目简介。

文档已去掉个人绝对路径和历史会话链接。通用真实链路验证脚本保留，每次默认使用新的测试用户标识；它仅在明确运行时上传 PDF 并调用真实服务。

## 配置、作品与许可

源码副本整理及跨机器配置适配已完成，安装与运行说明见 [setup.md](setup.md)。真实流程视频、截图及可离线打开的模拟示例见 [作品说明](demo.md)。

两个 API 使用各自的项目虚拟环境；WSL 名称、解释器和模型位置不再固定。GPU 模型服务仍需要符合要求的 Linux/WSL 环境或可连接的远程服务；本副本不自带权重或凭据。

原创部分按作者选择采用 [MIT 许可](../LICENSE)。第三方组件、模型和论文材料的适用范围见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

本轮干净环境与真实链路验证见 [复现记录](reproducibility.md)。
