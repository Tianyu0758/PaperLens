## 环境与方法

从发布源码复制到包含中文与空格的干净目录，分别创建全新的 Agent、RAG Python 3.12 虚拟环境，通过依赖清单安装包并记录锁定版本；没有复制开发项目的虚拟环境或数据库。

Grobid 0.8.0 和 Qdrant 1.19.0 使用本次独立 Compose 项目启动，分配独立端口、全新的 Qdrant volume 与集合。两个 API 使用新安装的 Windows 环境。Embedding 与 Reranker 经新入口在 WSL 中启动，显式配置解释器和模型位置；该 GPU 环境复用了已有 vLLM 0.8.5、PyTorch 2.6.0/CUDA 12.4 及模型权重。

## 验证范围与限制

- 这是同一台电脑上的干净目录和全新 CPU API 环境复现，未在第二台实体机器或全新 Linux 系统上测试。
- GPU 环境和权重是显式复用的，未重新下载全部权重或从零安装 CUDA/vLLM；安装手册列出了相应步骤和官方兼容要求。
- 模型 API 仍需读者自己的有效凭据与模型名称。`doctor` 检查配置和 HTTP 可达性，不检查余额或模型回答质量。
- 浏览器规则检查与测试通过不等同于论文结论得到人工审核。
